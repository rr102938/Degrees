# Degrees of Separation (CS50 AI)

## What it does
* This is a Python program that finds the shortest path of movies and shared co-stars connecting any two actors or actresses using breadth-first search (BFS).
* It loads data from CSV files containing people, movies, and starring relationships, mimicking the "Six Degrees of Kevin Bacon" game.

## Technologies Used
* Python
* CSV data processing
* Breadth-First Search (BFS) algorithms
* Git / GitHub

## How to Run It
* Make sure you are in the project directory containing the data files.
* Run the main script with the dataset folder (e.g., `small` or `large`):
* "```bash"
* python degrees.py large
* Type the name of the first actor when prompted, then type the name of the second actor to see their degrees of separation and the movies they starred in together.
